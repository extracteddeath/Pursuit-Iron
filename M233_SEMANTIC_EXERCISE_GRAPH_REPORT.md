# M233 — Semantic exercise graph

Engine 0.65.5 / Build 822 integration candidate.

The semantic graph uses canonical catalog snapshots and the existing knowledge-node owner. Lazy immutable edges distinguish intent transfer from complementary stimulus. Movement subslot, joint actions, functional bias, primary stimulus, compound class, laterality, strength specificity, equipment and avoidance determine compatibility. Phase continuity now calls this single semantic gate instead of a broad muscle-vector heuristic.

Custom semantic claims use an explicit v1 record with movement subslot, joint actions, functional biases, load convention, range of motion and laterality. Cross-exercise inference requires high metadata confidence and those explicit claims. Missing/unknown metadata remains usable as an authored exercise but cannot manufacture transfer evidence from its name. Future/malformed semantic records fail at request normalization.

Numeric loads have a stricter contract than stimulus. Different machine stacks, per-hand conventions, complementary functions and unknown ranges receive no numeric equivalence. Reviewed full-range specific barbell variants can supply an 80% starting reference from at least two complete, reported-effort observations. The reference is rounded down to actual loading, limited to recent owned program/day history, and never earns progression. Readiness/edit/interruption/discomfort limitations refuse transfer. Saved source prescription identity, rather than the current swapped roster, identifies the observation.

Validation covers graph immutability, custom-schema refusal, complementary-function and strength mismatches, equipment overrides/avoidance, unit-aware bounded numeric transfer, additive provenance and the actual shell starting-reference bridge. Golden initial programs and existing adaptation/phase gates remain the regression boundaries.
