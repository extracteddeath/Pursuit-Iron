## Branch hygiene

The one-time merged-branch workflow deletes only unprotected branch tips **exactly equal to a successful merged PR head**. It preserves `main`, `beta`, open PR heads, forks, changed-after-merge branches and unreviewed/unmerged work. It re-fetches each head immediately before deletion and reports totals in the Actions summary. For later use, the Actions manual trigger defaults to **dry run**; manual deletion requires the literal `DELETE-MERGED` confirmation.
