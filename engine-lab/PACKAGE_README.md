# Pursuit Iron canonical engine

This package contains the exact production computation used by the app. Import `index.js` for generation, cycle, history and workout APIs, or its `shell` namespace for custom/template compatibility calculations. No React or browser is required. UI source is retained under `reference` only as integration evidence.

Run `npm run verify` for source identity and `npm test` for semantic regression gates. Snapshot edits invalidate the hashes; maintain changes in the application repository and re-export into an empty directory. The package is a distribution of that source, not an independent fork.
